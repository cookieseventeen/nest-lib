# 影片API前端Demo應用程式

這是一個完整的前端Demo應用程式，展示如何與NestJS影片API後端進行對接。

## 📁 專案結構

```
frontend-demo/
├── index.html              # 主頁面
├── styles.css              # 主要樣式檔案
├── script.js               # 主要應用程式邏輯
├── config.js               # 設定檔案
├── api/                    # API層
│   ├── utils.js            # 工具函式庫
│   ├── auth.js             # 身份驗證API
│   └── video.js            # 影片API
└── components/             # UI元件
    ├── auth.js             # 認證元件
    ├── video-player.js     # 影片播放器元件
    ├── video-list.js       # 影片列表元件
    └── downloader.js       # 下載器元件
```

## 🛠️ 安裝和使用

### 前置需求
- 現代網頁瀏覽器（Chrome、Firefox、Safari、Edge）
- NestJS後端服務正在執行
- 適當的CORS設定

### 設定步驟

1. **設定API端點**
   編輯 `config.js` 檔案：
   ```javascript
   const CONFIG = {
     API_BASE_URL: 'http://localhost:3000', // 修改為您的後端URL
     // 其他設定...
   };
   ```

2. **啟動後端服務**
   確保NestJS後端正在執行並可存取。

3. **開啟前端應用程式**
   直接在瀏覽器中開啟 `index.html` 檔案，或使用本地HTTP伺服器：
   
   使用Python：
   ```bash
   python -m http.server 8080
   ```
   
   使用Node.js：
   ```bash
   npx http-server
   ```

4. **開始使用**
   - 註冊新帳號或登入現有帳號
   - 開始下載和管理影片

## 🔧 設定選項

### API設定 (`config.js`)
```javascript
const CONFIG = {
  API_BASE_URL: 'http://localhost:3000',    // 後端API基礎URL
  ITEMS_PER_PAGE: 12,                       // 每頁顯示的影片數量
  MAX_BATCH_DOWNLOADS: 10,                  // 批量下載最大數量
  SUPPORTED_FORMATS: ['mp4', 'webm', 'avi'], // 支援的影片格式
  CACHE_TIMEOUT: 5 * 60 * 1000,            // 快取逾時時間（毫秒）
  RETRY_ATTEMPTS: 3,                        // 請求重試次數
  REQUEST_TIMEOUT: 30000                    // 請求逾時時間（毫秒）
};
```

## 🎮 使用指南

### 註冊和登入
1. 開啟應用程式
2. 點擊「沒有帳號？立即註冊」
3. 填寫註冊表單
4. 使用新帳號登入

### 下載影片
1. 切換到「下載器」分頁
2. 選擇單一或批量下載模式
3. 輸入影片URL
4. 選擇影片格式
5. 點擊「開始下載」

### 播放影片
1. 在「影片列表」中找到要播放的影片
2. 點擊「播放」按鈕
3. 使用播放器控制項操作

### 管理影片
1. 在「影片列表」中檢視所有影片
2. 使用搜尋框尋找特定影片
3. 使用過濾器篩選影片
4. 點擊「刪除」按鈕移除不需要的影片

## ⌨️ 鍵盤快捷鍵

### 全域快捷鍵
- `Ctrl/Cmd + 1`: 切換到下載器分頁
- `Ctrl/Cmd + 2`: 切換到影片列表分頁
- `Ctrl/Cmd + 3`: 切換到播放器分頁
- `Ctrl/Cmd + ,`: 開啟設定
- `Esc`: 關閉對話框

### 播放器快捷鍵
- `空白鍵`: 播放/暫停
- `←`: 後退10秒
- `→`: 前進10秒
- `↑`: 增加音量
- `↓`: 減少音量
- `M`: 靜音/取消靜音
- `F`: 全螢幕/退出全螢幕

## 🐛 故障排除

### 常見問題

**無法連接到後端**
- 檢查後端服務是否正在執行
- 確認 `config.js` 中的API_BASE_URL設定正確
- 檢查網路連線

**登入失敗**
- 確認使用者名稱和密碼正確
- 檢查後端認證服務是否正常
- 清除瀏覽器快取和Cookie

**影片無法播放**
- 確認影片檔案存在於伺服器
- 檢查瀏覽器是否支援影片格式
- 確認網路連線穩定

**下載失敗**
- 檢查影片URL是否有效
- 確認後端下載服務正常
- 檢查磁碟空間是否足夠

### 偵錯技巧

1. **開啟瀏覽器開發者工具**：檢查主控台錯誤和網路請求
2. **檢查網路分頁**：查看API請求和回應
3. **檢查儲存空間**：確認localStorage資料
4. **檢查後端日誌**：查看伺服器端錯誤資訊
